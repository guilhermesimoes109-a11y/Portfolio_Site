# DEV Portfolio — réplica personalizada

Página estática responsiva em HTML + CSS + JavaScript.

## Tecnologias incluídas
- HTML & CSS
- Visual Basic.NET
- C
- BASH
- .NET Framework
- ASP.NET
- MySQL
- Git (experiência com versionamento, branches, commits e merge)
- Python

## Estrutura
Cada secção é agora uma página HTML própria, partilhando o mesmo cabeçalho, rodapé, estilos e script:
- `index.html` — Início
- `sobre.html` — Sobre
- `tecnologias.html` — Tecnologias
- `experiencia.html` — Experiência
- `contacto.html` — Contacto
- `style.css` — design responsivo
- `script.js` — menu mobile
- `assets/` — imagens dos logótipos das tecnologias

Abra `index.html` diretamente no navegador e navegue pelo menu. Não são necessárias dependências externas.
